# py-bumpver-release-action (by markcallen)

Reusable GitHub workflow for Python projects that:

1. Bumps version in `pyproject.toml` using bumpver
2. Commits & tags
3. Pushes changes
4. Creates a GitHub Release
5. Optionally generates release notes using AI via `markcallen/ai-release-notes-action`

If AI is disabled or fails, it falls back to GitHub autogenerated release notes.

## Usage from a project repo

```yaml
name: Release

on:
  workflow_dispatch:
    inputs:
      level:
        type: choice
        options: [patch, minor, major]
        default: patch
      use_ai_release_notes:
        type: boolean
        default: false

jobs:
  bump-and-release:
    uses: markcallen/release-tools/examples/py-bumpver-release-action/.github/workflows/bumpver-release.yml@v1
    with:
      level: ${{ github.event.inputs.level }}
      use_ai_release_notes: ${{ github.event.inputs.use_ai_release_notes }}
    secrets:
      OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
```

Your project must configure `pyproject.toml` with bumpver, for example:

```toml
[project]
version = "0.1.0"

[tool.bumpver]
current_version = "0.1.0"
version_pattern = "MAJOR.MINOR.PATCH"

[tool.bumpver.file_patterns]
"pyproject.toml" = ['version = "{version}"']
```

After pushing this repo, tag it (e.g. `v1`) and refer to that tag in callers.
