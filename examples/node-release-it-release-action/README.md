# node-release-it-release-action (by markcallen)

Reusable GitHub Actions workflow for Node.js projects using `release-it`.
It will:

1. Run `release-it` to bump version, commit, and tag
2. Push commits and tags
3. Create a GitHub Release
4. Optionally generate release notes using AI via `markcallen/ai-release-notes-action`
5. Fall back to GitHub autogenerated notes if AI is disabled or fails

## Requirements in the caller project

- Node project with `package.json`
- `release-it` installed (usually as a devDependency)
- `release-it` configured **not** to create GitHub releases itself, for example:

```jsonc
{
  "devDependencies": {
    "release-it": "^17.0.0"
  },
  "release-it": {
    "git": {
      "commitMessage": "chore(release): v${version}",
      "tagName": "v${version}"
    },
    "github": {
      "release": false
    },
    "npm": {
      "publish": false
    }
  }
}
```

## Usage from a project repo

```yaml
name: Release (Node + release-it)

on:
  workflow_dispatch:
    inputs:
      level:
        description: "Version bump level"
        type: choice
        default: patch
        options: [patch, minor, major]
      use_ai_release_notes:
        description: "Use AI (OpenAI) to generate release notes"
        type: boolean
        default: false

jobs:
  release:
    uses: markcallen/release-tools/examples/node-release-it-release-action/.github/workflows/release-it-bump.yml@v1
    with:
      level: ${{ github.event.inputs.level }}
      use_ai_release_notes: ${{ github.event.inputs.use_ai_release_notes }}
    secrets:
      OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
```

After pushing this repo, tag it (e.g. `v1`) and use that tag in callers.
